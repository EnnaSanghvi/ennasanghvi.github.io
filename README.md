# Personal website: Enna Sanghvi

A static, multi-page site (no build step) for GitHub Pages.

## Files
- `index.html`: home
- `story.html`: narrative of your path and research themes
- `research.html`: the three threads (Dynamics, Heterogeneity, Context & care)
- `publications.html`: filterable publications, presentations, posters
- `experience.html`: filterable research and clinical timeline
- `cv.html`: education, awards, skills, training, service
- `style.css`, `script.js`: shared styling and behavior
- `assets/Enna_Sanghvi_Resume.pdf`: downloadable resume

## Publish on GitHub Pages
1. Sign in at github.com and click **New repository**.
2. Name it `<your-username>.github.io` (this gives you the root URL `https://<your-username>.github.io`). Set it to **Public** and create it.
3. Click **Add file → Upload files**, drag in everything in this folder (keep the `assets` folder), and commit.
4. Go to **Settings → Pages**. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, and save.
5. Wait a minute or two, then visit your URL.

## Before you publish
- Google Scholar links are already set to your profile.
- Review the content for anything you'd rather not make public.
- To update the resume, replace `assets/Enna_Sanghvi_Resume.pdf`.
